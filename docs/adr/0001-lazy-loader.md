# ADR-001: Использование LazyLoader для отложенной загрузки LLM и эмбеддингов

## Статус
Принято

## Контекст
Приложение должно поддерживать разные провайдеры LLM (Ollama, OpenRouter, HuggingFace) и тяжелые модели эмбеддингов. Немедленная загрузка всех компонентов при старте приведёт к долгому запуску и высокому потреблению памяти, даже если пользователь не будет использовать LLM.

## Решение
Внедрен singleton-класс `LazyLoader` в `config.py`: загружает LLM, эмбеддинги и реранкер только при первом обращении через `get_llm()`, `get_embeddings()`, `get_reranker()`. Это позволяет стартовать приложение мгновенно и экономить ресурсы.

## Последствия
- Простой переключение провайдеров через переменные окружения.
- Возможность замены провайдера без перезапуска (т.е. после смены конфига потребуется перезагрузка).
- Отсутствие overhead при отсутствии вызовов LLM.
