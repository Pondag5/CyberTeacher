# ADR-003: Кэширование ответов LLM через SQLite с TTL

## Статус
Принято

## Контекст
LLM вызовы дорогостоящие (время, токены, нагрузка на провайдера). При запросах с одинаковым/похожим контекстом пользователя повторные вызовы неоправданны.

## Решение
В `memory.py` создана таблица `query_cache`, где ключом является хэш запроса (включая режим и контекст). Ответы кэшируются с TTL:
- Актуальные данные (новости, угрозы) — 1 день.
- Теория, объяснения — бессрочно (ttl=None).

При каждом вызове LLM сначала проверяется кэш. Если命中 — возвращается сохранённый ответ.

## Последствия
- Снижение количества запросов к LLM на 30–70% в активной сессии.
- Возможность работы в оффлайне после заполнения кэша.
- Требуется чистка просроченных записей (выполняется при старте и после каждого вызова get_cached_response).
