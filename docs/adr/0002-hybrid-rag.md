# ADR-002: Гибридный поиск по базе знаний (Vector + BM25)

## Статус
Принято

## Контекст
Чисто векторный поиск (semantic) может плохо находить документы по редким техническим терминам (имя инструмента, протокола, CVE). Нужен способ учитывать точное совпадение ключевых слов без потери семантики.

## Решение
В `knowledge.py` реализован гибридный поиск:
1. Сначала извлекается top-K (по умолчанию 10) векторно-похожих чанков.
2. Параллельно выполняется BM25-ранжирование по ключевым словам (с токенизацией для кириллицы через `jieba`).
3. Scores объединяются (RRF — Reciprocal Rank Fusion) для получения финального порядка.

Это обеспечивает высокую релевантность и защиту от "пропуза" специфичных терминов.

## Последствия
- Требует индекса BM25 (обсчитан при загрузке документов).
- Небольшой overhead на вычисление BM25, но оно происходит только при запросе.
- Улучшает recall без ущерба precision.
