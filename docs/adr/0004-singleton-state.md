# ADR-004: Глобальное состояние через singleton AppState

## Статус
Принято

## Контекст
Разные части приложения (handlers, main, knowledge) нуждаются в доступе к общему состоянию: points, weak_topics, режим, контекст обучения. Передавать state через аргументы везде неудобно и легко leads to inconsistencies.

## Решение
В `state.py` определён dataclass `AppState` содержащий все глобальные переменные. Создаётся единственный экземпляр `app_state`, доступный через функцию `get_state()`. Все модули используют `get_state()` для чтения/записи. Состояние периодически сохраняется в `memory/app_state.json`.

## Последствия
- Упрощает доступ к глобальным данным.
- Необходимо быть аккуратным с многопоточностью (приложение однопоточное, поэтому безопасно).
- Миграция старого кода: постепенная замена передачи state через аргументы.
