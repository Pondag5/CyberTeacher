# Индивидуальный Roadmap для CyberTeacher

Этот документ описывает развитие проекта **как личного тренажёра для одного пользователя**. Командные функции,multi-user и restaurant-features исключены из приоритетов.

---

## 📌 Приоритеты (нужны в первую очередь)

### M-25: HackTheBox / TryHackMe Integration
**Цель:** Импортировать внешние платформы как миссии.  
**Что даёт:** Доступ к сотням реальных машин, разнообразие сложностей.  
**Как:** API HTB/THM → `missions/htb_<id>.json` с инструкциями по развёртыванию.  
**Статус:** Not started

### M-26: Step-by-Step Exploit Walkthroughs
**Цель:** После прохождения лаборатории показывать интерактивный разбор уязвимости.  
**Что даёт:** Глубокое понимание *почему* работает эксплойт, а не просто копирование флага.  
**Как:** `walkthroughs/` папка с пошаговыми сценариями (код, запросы, ответы, shell commands). Команда `/walkthrough <mission_id>`.  
**Статус:** Not started

### M-27: Exploit Submission (PoC verification)
**Цель:** Заменить флаги на проверку скрипта-эксплойта в песочнице.  
**Что даёт:** Оценивается реальное умение эксплуатировать, а не угадывать.  
**Как:** `/exploit <mission_id>` принимает Python/Bash код → запускает в sandbox → ищет флаг в stdout/files → оценивает время/эффективность.  
**Статус:** Not started

### M-28: Bug Bounty Simulation
**Цель:** Имитация реального bug bounty цикла.  
**Что даёт:** Практика написания отчётов, получения feedback, работы с ребаундами.  
**Как:** `/bounty submit` → загрузка PoC + описание → LLM как рецензент (оценка clarity, impact, PoC quality) → награда (виртуальные деньги).  
**Статус:** Not started

### M-29: Learner Dashboard (персональная аналитика)
**Цель:** Detalized статистика по прогрессу.  
**Что даёт:** Понимание, что нужно улучшать, мотивация через графики.  
**Как:** Расширение `web_ui.py`: вкладки "Progress" (графики XP over time, success_rate по темам, heatmap активности).  
**Статус:** Not started

### M-30: Adaptive Learning Tracks
**Цель:** Персонализированные обучающие треки вместо линейного story mode.  
**Что даёт:** Учитель подстраивает путь под сильные/слабые стороны.  
**Как:** `tracks/` YAML-файлы (например, "Web Security 101" → 10 шагов). Движок проверяет weak_topics и предлагает следующий шаг. Можно пропустить темы с high score.  
**Статус:** Not started

### M-31: Real-time Hints & Co-pilot
**Цель:** Контекстные подсказки во время лаборатории, а не только до/после.  
**Что даёт:** Не застрять, получить помощь в моменте.  
**Как:** Мониторинг ввода в `main.py`; при запросе `/hint` → LLM генерирует подсказку на основе истории действий и типа лаборатории. Лимит подсказок (например, 5 за лабораторию).  
**Статус:** Not started

### M-32: Advanced Analytics & AI Tutor
**Цель:** Графики + рекомендации от LLM на основе всех данных.  
**Что даёт:** Проактивное обучение, предсказание выгорания.  
**Как:** Команда `/ai_recommend` → LLM анализирует метрики ( XP, weak_topics, time spent) и выдаёт советы: "Сфокусируйся на X", "Повтори Y через 3 дня".  
**Статус:** Not started

### M-33: Mobile Companion App (PWA)
**Цель:** Тренироваться с телефона.  
**Что даёт:** Регулярность, микро-квизы в любом месте.  
**Как:** React/Flutter Web App, кэширование, push-уведомления о напоминаниях, sync через API.  
**Статус:** Not started

### M-34: Voice Assistant (TTS/STT)
**Цель:** Голосовой ввод/вывод для удобства.  
**Что даёт:** Возможность практиковаться, не глядя на экран.  
**Как:** Vosk (STT) + Coqui TTS / Silero. Голосовая команда `/hint` → синтез ответа.  
**Статус:** Not started

## ❌ Исключено (не для индивидуального использования)

- **M-28 Multi-user & Leaderboard** — требует серверной инфраструктуры и много пользователей  
- **M-29 Instructor Dashboard** — замена на Learner Dashboard  
- **M-02 Red vs Blue мультиплеер**  
- **M-14 Плагинная архитектура** — избыточна для одного пользователя  
- **M-13 SCORM/LTI** — интеграция с LMS  
- **M-16 Видео/подкасты внутри** — лучше внешние ссылки  
- **M-19 Голосовой учитель** — перенесён в M-34 (TTS/STT)  
- **M-20 Кроссплатформенная синхронизация** — не нужно без multi-device  
- **M-22 Sumarization истории** — частично есть в `/auto_writeup`  
- **M-23 Расширение QUIZ_TOPICS** — уже делается через knowledge base  
- **M-24 Команда /help detail** — уже Done  
- **M-18 Временная петля** — низкий приоритет  
- **M-19 Эмоции учителя** — низкий приоритет  
- **M-28 Система репутации** — без multi-user не нужно
