## Рефакторинг (REF-01 — REF-15)

### REF-01: Registry Pattern для handlers
**Статус:** Done
**Описание:** Рефакторинг handlers/core.py с использованием registry pattern для регистрации обработчиков.

### REF-02: Модульная архитектура state
**Статус:** Done
**Описание:** `AppState` использует 10 модульных компонентов через композицию. `__getattr__`/`__setattr__` делегируют атрибуты к модулям. Все методы делегируют к соответствующим модулям.
**Результат:** state.py: 1019 → 885 строк (-13%), 10 файлов ~428 строк суммарно.

### REF-03: Дублирование данных в модулях состояния
**Статус:** Done
**Описание:** `xp_boost_multiplier` и `xp_boost_expiry` существовали одновременно в `achievements_state.py` и `shop_state.py`. Перемещены в `shop_state.py` как единый источник.

### REF-04: Dependency Injection (вместо глобального singleton)
**Статус:** Done
**Описание:** Все 60+ хендлеров мигрированы с `get_state()` → `get_context().state`. `di.py` — AppContext container с state, settings, db_conn, llm, kb. `@inject` decorator для handler injection.
**Результат:** 985 тестов проходит, 0 ошибок, 4 skipped.

### REF-05: Циклические импорты
**Статус:** Done
**Описание:** Mode enum вынесен в `shared_types.py`, устранены циклические импорты `state.py` → `ui.py`.

### REF-06: `__getattr__` / `__setattr__` делегирование
**Статус:** Done
**Описание:** Заменено на явные `@property` в `state.py`. IDE и линтеры теперь видят реальную структуру данных.

### REF-07: Ручная сериализация → Pydantic v2

## Известные баги (решены 2026-05-17)

### BUG-06: /export падал из-за None conn
**Проблема:** `handle_export` вызывал `get_chat_history(conn=None)`, что приводило к `AttributeError`.
**Решение:** Теперь берёт `conn` из `get_context().db_conn`.

### BUG-07: /api и /pwa крашились
**Проблема:** `handle_api` и `handle_pwa` возвращали `tuple[str, bool]` вместо `tuple[bool, Any, Any, bool]`.
**Решение:** Исправлены сигнатуры и парсинг аргументов.

### BUG-08: PWA показывала старую версию
**Проблема:** Service Worker кэшировал старые файлы, `Cache First` стратегия.
**Решение:** Переход на `Network First`, `skipWaiting()`, `clients.claim()`, версионирование кэша.

### BUG-09: settings.py не принимал groq
**Проблема:** `Literal["ollama", "openrouter", "huggingface"]` не включал `groq`.
**Решение:** Добавлен `groq` в Literal.

### BUG-10: /api/stats дубликат эндпоинта
**Проблема:** Два `@app.get("/api/stats")` — старый без полей activity/skills вызывал JS ошибку.
**Решение:** Удалён дубликат, оставлен расширенный `/api/stats`.

### BUG-11: PWA 404 на статике
**Проблема:** `/style.css`, `/script.js`, `/icon-192.png` возвращали 404.
**Решение:** Добавлены маршруты в `api_server.py`.
